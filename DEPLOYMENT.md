## Quick Deploy (Vercel)

### One-Click

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/YOUR_USERNAME/sansas-kitchen)

### Manual Setup

```bash
# 1. Install Vercel CLI
npm i -g vercel

# 2. Login
vercel login

# 3. Deploy
vercel --prod
```

### Git Auto-Deploy

Push to GitHub/GitLab → Vercel auto-deploys:

1. Go to [vercel.com/new](https://vercel.com/new)
2. Import your Git repository
3. Click **Deploy**

Every `git push` to `main` triggers automatic deployment.

## Domain Setup

### Vercel

1. Dashboard → Settings → Domains
2. Add your domain (e.g. `sansas.kitchen`)
3. Update DNS records at your registrar:
   - **CNAME** `@` → `cname.vercel-dns.com`
   - Or use Vercel nameservers

### SSL/TLS

Vercel auto-provisions Let's Encrypt certificates. HTTPS enabled by default.

---

## Environment Variables

Set these in Vercel Dashboard → Settings → Environment Variables:

```
VITE_APP_NAME=Sansa's Kitchen
VITE_APP_TAGLINE=Cook with Love, Create with Magic.
VITE_BASE=/
VITE_ENV=production
```

For custom API backends:

```
VITE_API_URL=https://api.your-backend.com
```

## Build & Deploy

```bash
# Install
npm install

# Build for production
npm run build
# Output: dist/

# Preview locally
npm run preview
# → http://localhost:4173

# Deploy to Vercel
vercel --prod

# Deploy to Netlify
netlify deploy --prod --dir=dist
```

## Troubleshooting

### 404 on sub-routes after refresh

→ Check `vercel.json` rewrites rule is present.

### Logo not showing

→ Verify `public/Sansa/logo.png` exists (1254×1254, ~1.8MB).

### Fonts not loading

→ Vercel domains and custom domains auto-inherit the Google Fonts CDN in CSP.

### Build fails

```bash
# Check TypeScript
npx tsc --noEmit

# Test build locally
npm run build
npm run preview
```
